# 🫀 CardioCare AI

An enterprise-grade MedTech platform powered by Machine Learning to assist in heart health predictions and care management.

## 🎯 Overview
CardioCare AI is a full-stack web application designed to bridge healthcare and technology. It utilizes a trained machine learning model to analyze medical data and provide insights. The platform features a dynamic frontend interface integrated seamlessly with a secure backend.

## 🚀 Tech Stack
* **Backend:** Python, Flask
* **Machine Learning:** Scikit-Learn (Joblib models)
* **Database:** SQLite
* **Frontend:** HTML, CSS

## ✨ Key Features
* **ML-Powered Diagnostics:** Predictive modeling using custom-trained algorithms (`heart_disease_brain.joblib`).
* **Secure Access:** Role-based authentication for different user levels.
* **Smart Interaction:** Integrated voice chatbot capabilities for enhanced user experience.
* **Dynamic Interface:** Multi-page layout with a clean, responsive design.

## 🛠️ How to Run Locally
To run this project on your own machine, follow these steps:

1. **Clone the repository:** Download the files to your computer.
2. **Set up the database:** Run the database initialization script by typing `python setup_db.py` in your terminal.
3. **Start the server:** Run the main application by typing `python app.py` in your terminal.
4. **Access the platform:** Open your web browser and go to `http://127.0.0.1:5000`.
